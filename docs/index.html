Can an AI answer Spotify's support tweets, and when should we let it?

An agent classifies each incoming tweet, drafts a reply grounded in how @SpotifyCares handled similar tweets, and decides whether a human must take over. Everything below is measured against labels written by hand, and can be reproduced without API keys.
